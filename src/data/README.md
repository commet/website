# Map geography

`land-110m.json`: Natural Earth 1:110m land, distributed by [world-atlas 2.0.2](https://github.com/topojson/world-atlas) (ISC). Natural Earth geographic data is in the public domain. Downloaded from the versioned npm distribution on 2026-11-02.

Only geography is bundled. Observation positions come from the existing public NASA EONET and USGS APIs. The map does not infer coordinates for NWS alerts or turn event locations into transport impact.
